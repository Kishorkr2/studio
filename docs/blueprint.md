# **App Name**: TyreTrack Pro

## Core Features:

- Operator & Shift Management: Admin Panel for managing approved operator lists and shift timings, and uploading market requirement data from Excel files.
- Real-Time Production Entry: Interactive Production Panel for hourly data entry for each of the 26 Tyre Building Machines, including SKU and auto-sync functionality, supporting online and offline storage.
- Advanced Reporting & Analytics: Reporting Panel to filter, display, and export detailed/summarized reports by date, shift, operator, TBM, and SKU in Excel format.
- Light/Dark Mode Toggle: Ability to toggle between light and dark mode.
- Optimized Operator Assignment: Generative AI powered tool that suggests a best assignment of operators to the 26 machines, given operator skill ratings, shift times and absenteeism.
- Automated Notifications: Push notifications for missing hourly production data.

## Style Guidelines:

- Primary color: Strong blue (#29ABE2) representing reliability and industrial processes.
- Background color: Light gray (#F5F5F5) providing a clean and neutral backdrop for data visibility.
- Accent color: Vibrant orange (#FF8C00) to highlight crucial alerts and interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, clear, and easily readable interface.
- Use consistent and clear icons to represent different machines, shifts, and data metrics.
- Organize each panel with intuitive navigation, emphasizing real-time data and actionable insights.
- Subtle transitions and animations for data updates to provide a smooth user experience.
